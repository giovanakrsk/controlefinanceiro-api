# controlefinanceiro-api

API REST desenvolvida em Java com Spring Boot para a disciplina de desenvolvimento de APIs. O sistema permite o registo e a gestão de movimentações financeiras, calculando dinamicamente o saldo mensal disponível.

## Tecnologias Utilizadas
* **Java**
* **Spring Boot** (Web, Data JPA, Validation)
* **Base de Dados H2** (Em memória)
* **Maven**
* **Postman** (Testes de Integração e Validação de Endpoints)

## Como Executar o Projeto

1. Certifique-se de que tem o Java e o Maven instalados na sua máquina.
2. Faça o clone deste repositório.

## Testes e Validação (Postman)
Todos os endpoints desta aplicação foram testados utilizando o Postman, garantindo o correto funcionamento do fluxo de dados e das regras de negócio.
